# OpenFOAM environment (external system dependency)

OpenFOAM is **not** a pip package. The neck-flow CFD cases were generated by this package and run with a specific
distribution; reproduce with the same one.

## Reported distribution

- **OpenFOAM 2606 (ESI / openfoam.com fork)** is the development environment reported in the historical run notes.
  The exact patch build is not independently recoverable from the released records. Do not assume the same
  behaviour from another fork or version; the foundation `.org` builds differ in dictionary syntax.
- Solver: `pimpleFoam` (incompressible, laminar, imposed oscillating flow through one neck, 5° wedge, adaptive
  time step through `maxCo`).
- Meshing: `blockMesh`; checks with `checkMesh`.

## OS and runtime

- Run under **WSL2 (Ubuntu)** on Windows, or native Linux.
- Source the environment before solving: `source /usr/lib/openfoam/openfoam2606/etc/bashrc`.

## How the cases are run

The package writes a portable bundle of cases on one machine; OpenFOAM runs them on the other; the results are
copied back and hashed before anything reads them.

```
acoustic-liner vehicles cfd-bundle bundle --vehicle falcon      # writes the bundle and its run_cases.sh
bash run_cases.sh nominal 4                                     # in WSL, inside the copied bundle; resumable
acoustic-liner vehicles cfd-bundle returned  --bundle DIR       # hash every returned file
acoustic-liner vehicles cfd-bundle aggregate --bundle DIR       # valid rows -> per-bank R(U), X(U)
```

Each case runs `blockMesh`, `checkMesh` and `pimpleFoam`, each with its own log.

## What is recorded

- Every case has an identity file with its inputs and an input-tree hash; a returned case must hash the same as
  the generated one.
- A row of R(U), X(U) is accepted only with a passing `checkMesh` log, a complete solver log and the validation
  checks of `acoustic_liner.cfd.validation`.
- Each verdict record lists the OpenFOAM build read from its cases and is refused if the builds differ.
- The raw cases, logs and sampling histories are part of the private archive and are not distributed.

The exact patch build of OpenFOAM is not pinned by this repository and is not stated in the released records.
